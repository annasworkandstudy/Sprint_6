Проект автотестов для сервиса «Самокат»
Данный проект содержит автоматизированные тесты на Python с использованием Pytest и Selenium. Проект реализован по модели Page Object Model (POM).
📁 Структура проекта
locators/ — классы с локаторами элементов (FAQ, заказ, логотипы).
pages/ — классы с методами взаимодействия со страницами (Page Objects).
tests/ — тестовые сценарии (тесты аккордеона, оформления заказа, кликов по логотипам).
conftest.py — фикстуры для инициализации драйвера и ожиданий.
🚀 Запуск тестов
Установка зависимостей:
bash
pip install pytest selenium allure-pytest

Запуск всех тестов:
bash
pytest

Запуск с генерацией данных для Allure:
bash
pytest --alluredir=allure-results

📊 Работа с отчетами Allure
Чтобы превратить сырые результаты в красивый отчет, тебе понадобится установленный на компьютер Allure Commandline.
Команды для формирования отчета:
Генерация и открытие временного отчета:
Эта команда создаст отчет в папке allure-report и сразу откроет его в твоем браузере.
bash
allure serve allure-results

Если нужно просто создать папку с отчетом (без открытия):
bash
allure generate allure-results -o allure-report --clean

Если папка с отчетом уже есть и её нужно открыть:
bash
allure open allure-report
